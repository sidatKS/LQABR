Guarantees the design encodes

Deterministic by default — same input, same outcome; the tokens log staying empty is the proof a run used no model. One write path — both front doors (in-process import and the MCP server) end in the same crm.py functions. Never drop a lead — every non-pushed lead lands in an error file with a reason; systemic failures halt before per-lead noise. No secrets at rest — files and image carry secret names; values exist only in Secret Manager and process memory. Lead data stays out of the model — profiles live in the process heap; even the opt-in console only ever sees counts and ids.
