Marketing publishes

  • blog_industry: HEALTHCARE · LEGAL_SERVICES · FINANCIAL_SERVICES

Agent Gateway

agents/gateway · route R-blog-summary

  • verifies the HubSpot signature
  • matches blog_summary non-empty
  • hands over ONLY the post's object_id
  • answers HubSpot inside its ~5s budget

Read the post

research · run_campaign()

  • get_blog_summary(object_id) — MCP
  • take blog_industry from the post
  • read once, reused for every lead
  • no industry ⇒ stop with a named reason

Who is in that industry

research_core/hubspot_direct.py

  • companies where industry == X
  • → each company's associated contacts
  • the one direct HubSpot read — the MCP has no listing tool
  • could-not-ask ≠ nobody-matched: refuses to run

Research + write, per lead

research · run_research()

  • get_lead_profile → company, title, industry

  • upsert_lead_profile → lead_context
  • note stripped to the note alone — no model narration
  • one lead's failure never stops the rest

STAGE 3 · VOICE — qualified leads get called; a real conversation crosses the hand-off line

HubSpot Contact

Gate, claim, dial

text_voice · text_voice.py + tools.py

  • stops: opted out · no phone · already in flight
  • claims INITIATED before dialing — unclaimable ⇒ not dialed
  • opens the call on that lead's lead_context

Vapi — the live call

external · no agent code runs

  • 3-question qualification script
  • voicemail detected by Vapi
  • posts the end-of-call report back

Classify + write back

text_voice · summarise_report / mcp_client

  • model reads the transcript → 1 of 4 outcomes
  • silence ⇒ voicemail, never "answered"
  • answered + engaged = 30 → 45 → 60

probability ≥ 60 → Scheduling Agent

  • lead is emailed real availability across time zones
  • a booking pins probability at 95
  • handed to a human rep — the pipeline's exit

One run_id per campaign, one correlation_id per lead — a blog post ties to the call it produced. Never lose a lead: bad records are flagged (bad-data: / crm-error:), never silently dropped.
