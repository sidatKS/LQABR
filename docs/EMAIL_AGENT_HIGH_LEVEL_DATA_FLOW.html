Email Agent — High-Level Data Flow

First outreach stage (E4). Two responsibilities: draft & send one personalized first-touch email per profiled lead, and listen for engagement (delivered / opened / clicked) to raise the lead's probability in HubSpot. It writes the signal; the orchestrator decides promotion.

Guardrails

  • Only emails real HubSpot contacts — verified inside the send tool, not trusted from the LLM.
  • Never fabricates profile facts, prior contact, or engagement.
  • Engagement is recorded only by the webhook processing a real Mailgun event.
  • Mailgun/HubSpot failures surfaced verbatim; retries are bounded backoff, never silent.

Known gap not deployed

  • webhook_app.py isn't stood up on Cloud Run yet — Mailgun has nowhere to push events.
  • Until then, sync manually via manual_mailgun_send.py (status/watch).
  • No HubSpot property persists cross-agent stage — it's inferred from probability everywhere.
