# agents/summary — Summary Agent (STANDALONE)
#
# This agent depends on NOTHING else in this repo. There is no
# `pip install -e packages/lqabr_core` step and no `COPY mcp mcp` in its
# image. Its only coupling to the rest of the system is a RUNTIME MCP
# connection to the HubSpot MCP container (LQABR_SUMMARY_MCP_BASE_URL).
#
# google-adk is pinned to the same version agents/lead_profile was built
# and tested against. Because this agent has its own image and its own
# virtualenv, this pin is free to differ from the other agents' — that is
# the point of the standalone contract.
